# S5 对焦识别模型研究交接

这是 LumiMod 独立的**私有研究仓库**，用于交接第一代 Panasonic LUMIX DC-S5 V2.9 对焦识别模型的分析、电脑端还原、训练实验和验证工具。它独立于 S5 模拟器工程。

**截至 2026-11-27，尚无通过验收、可替换原机的新模型。训练保持暂停。** 已恢复有图像识别能力的候选网络、完成有限训练，并定位误报、小脸监督及脸／头任务定义的问题；电脑端结果尚未证明与原厂 DSP 或相机等价。

## 仓库与压缩包

Git 保存 `af-research/` 中的研究源码、文档、采集工具和轻量证据摘要。Release 压缩包按相同目录结构补充 `af-research/artifacts/`、数据 manifest／来源元数据和实验检查点，解压后可对照各报告中的相对路径。`handoff/` 下记录逐文件 SHA-256、打包范围及缺少的外部输入。

实验检查点包含模型参数和优化器状态，**不是可刷固件**。压缩包包含少量用于边界验证的原ARM代码片段及合成输入；不包含完整原始固件。原始数据照片、Python环境、第三方源码缓存和参考论文／相机手册PDF未打包。来源链接、照片许可元数据和恢复入口保留。

当前实际验证环境是 macOS arm64。Linux／WSL需要另行核对；部分训练和推理脚本导入 `resource`，不承诺原生Windows直接运行。历史快照可能含原开发机绝对路径，它们用于审计，不应直接当作异机入口；详见交接说明。

## 获取与核验

```sh
gh repo clone LumiMod/s5-autofocus-research
gh release download af-handoff-2026-11-27 --repo LumiMod/s5-autofocus-research

```

在新目录解压交接ZIP，或解压到仓库同级后合并相同路径；先阅读交接说明再执行脚本。损失函数检查通过不代表允许自动恢复训练。外部原始S5组件、所需照片和运行时须按说明准备，程序不会代替真实缺失数据生成假输入。

历史来源是 `LumiMod/s5-emulator` 的对焦研究子目录；其冻结报告和历史URL按原样保留。此仓库的最新交接入口以上方链接为准。
